Gelen istek
(status==active,role!=guest);age>=18,price<500000

Query string'den gelen tek satır. ; = AND, , = OR. Sayı ve boolean otomatik tanınır.

SQL çıktısı
{
  type: "sql",
  payload: {
    conditions:
      "( status = ? OR role != ? )
       AND ( age >= ? OR price < ? )",
    values: ["active", "guest", 18, 500000]
  }
}

Neden FlexQL

Her endpoint'te aynı filtre kodunu yazmayı bırakın

Filtreleme her backend'in ortak ihtiyacı, ama çoğu zaman elle yazılan, test edilmeyen ve SQL injection riski taşıyan kodlarla çözülüyor.

❌ Elle yazılan filtre

  • Her endpoint için ayrı parse mantığı
  • String birleştirme, injection riski
  • Veritabanı değişince her şeyi yeniden yaz
  • Hangi kolonun filtrelenebileceği belirsiz

✅ FlexQL ile

  • Tek parse() çağrısı
  • Değerler her zaman ayrı parametre
  • Adaptörü değiştir, filtre aynı kalsın
  • Kolon ve operatör kuralları tek yerde
📖

Okunabilir sözdizimi

country==TR,country==DE;age>=18 — URL'de bile anlaşılır.

🔒

Parametreli SQL

Değerler koşuldan ayrı döner. Sürücünüze verin, string'e gömmeyin.

🛡️

Kolon koruması

password, token gibi kolonları kapatın, kolon başına operatör kısıtlayın.

🔀

5 adaptör, tek dil

SQL, Sequelize, MongoDB, Elasticsearch, TypeORM.

🌳

İç içe ifadeler

Parantezle gruplayın. Derinlik limiti ayarlanabilir, varsayılan 3.

🧩

TypeScript

Tip bildirimleri hazır. Bağımlılıksız TypeORM çıktısı.

Nasıl çalışır

Bir derleyici, string parser değil

Girdi asla çalıştırılmaz; token'lara, sonra ağaca, sonra hedef sorguya dönüştürülür. Bu yüzden denetlenebilir ve taşınabilirdir.

Query string→Lexer→Parser→AST→Adapter çıktısı
Adaptörler

Aynı filtre, istediğiniz backend

Hepsi status==active;age>=18 ifadesi üzerinden. Sadece adapter değişiyor.

Kullanım alanları

Filtre gereken her yerde fırsat

Kullanıcıdan filtre alan her ürün, aynı sorunu yaşar. FlexQL bunu bir kütüphane çağrısına indirir.

🌐

REST / GraphQL API'ler

?filter= parametresini tek satırda güvenli sorguya çevirin.

GET /users?filter=age>=18;status==active
📊

Admin panelleri

Tablo filtreleri için her ekrana özel sorgu yazmayın.

role==admin,role==editor
🏠

İlan ve e-ticaret

Fiyat, kategori, öne çıkan gibi çoklu filtreler.

price>=100000;(featured==true,city==IST)
🏢

Çok kiracılı SaaS

Hassas kolonları kapatıp müşterilere güvenle filtre açın.

columnProtect: { exclude: ["token"] }
🔁

Veritabanı geçişleri

Postgres'ten Mongo'ya veya Elasticsearch'e geçerken filtre katmanınız değişmesin.

adapter: "sql" → "mongo"
🤖

Araçlar ve otomasyon

Dahili araçlara, CLI'lara ya da yapay zekâ ajanlarına kısıtlı, doğrulanmış bir filtre dili verin.

rules: { age: [>, >=, <, <=] }
Güvenlik

Neyin filtrelenebileceğine siz karar verin

Yasaklı kolonlar ve kolon başına izinli operatörler. Kural dışı bir istek derleme aşamasında durur.

flexql.parse(
  "email==user@example.com;age>18",
  {
    adapter: "sql",
    columnProtect: {
      exclude: ["password", "token"],
      rules: {
        email: ["=="],
        age: [">", ">=", "<", "<="],
      },
    },
  }
);
Sözdizimi

Küçük, ama yeterli

Ayırıcılar özelleştirilebilir: separators: { and: "|", or: "&" }. İç içe gruplar için parantez kullanın.

==eşittir
!=eşit değildir
> <büyük / küçük
>= <=büyük eşit / küçük eşit
,OR
;AND
( )iç içe grup
